# HousePrice Evaluator

A small data preprocessing and exploration exercise using 110 property records. The focus is cleaning messy fields and examining how home characteristics relate to price.

![Property analysis snapshot](https://github.com/user-attachments/assets/85f6cfb9-b295-4b6c-87c5-0b07276f55ee)

## What the project covers

- Examine missing values, implausible entries, and outliers.
- Prepare numeric and categorical fields for analysis.
- Explore size, bedrooms, bathrooms, location, and sale price in the [notebook](Lab_2_Osualaaham.ipynb).

The dataset is included as [`house_prices-1.csv`](house_prices-1.csv). To explore the work locally:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
jupyter lab
```

Open `Lab_2_Osualaaham.ipynb` in Jupyter.

**Limitations:** With only 110 rows, the analysis is an exercise in data preparation; it does not establish a validated house valuation tool.
